Build switch:
- Default ARM64 (xterm.js): includes XtermRenderer.xcconfig, loads xterm-term.html → xterm-vendor/xterm-classic.js + addon-canvas.js + xterm-term-bridge.js
- Ghostty Web alternative: TERMINAL_RENDERER_DEFINES=USE_XTERM_RENDERER=0 loads term.html → ghostty-web.js + term.js
- Both renderers use the same native bridge API (window.exports / webkit.messageHandlers)

Runtime notes:
- xterm-classic.js is generated from xterm.mjs, addon-fit.mjs,
  addon-web-links.mjs, and addon-ligatures.mjs. Each source file is wrapped in
  its own IIFE, and ESM exports are rewritten to window.xtermModules. This
  matches the older iOS xterm integration's classic bundle shape, avoids
  top-level minifier variable collisions, and avoids WKWebView local module
  loading failures.
