# Apple AOT and Bun/Pi - 4 October 2026

## Available functionality

The separate iOS test app bundles Alpine 3.24.2 and Bun 1.4.2. It can include
ahead-of-time translations for musl, BusyBox and Bun without generating
executable code at runtime. Untranslated code uses the normal interpreter.
The reference app configurations keep the interpreter.

App updates preserve existing Linux files and packages. The installed version
and translation set can be checked in `/proc/ish/version`.
[Build instructions](../../NATIVE_AOT_IOS.md) describe how to create a matching
app and translation set.

## Runtime fixes

One Bun/Pi crash came from an incorrectly retried memory-clear instruction.
The retry repeated earlier pointer and length updates, causing memory outside
the intended buffer to be cleared. It now resumes at the instruction that
failed. The regression test checks that the pointer, register state and exact
write range are preserved.

Secure downloads failed because vector memory accesses selected the wrong
halfword within a register. This altered the keys used by Bun's post-quantum
TLS handshake. Correcting the lane selection fixes the reproduced key mismatch
and `BAD_DECRYPT` error. A separate vector-shift error was also corrected.

Bun sometimes reported the TLS failure as a certificate error. These fixes
do not disable certificate verification or replace Bun with another runtime.

## Tests

- Crypto output agrees with independent native Node results for AES/GCM,
  conventional key exchange and ML-KEM key derivation.
- TLS 1.3 works with hybrid post-quantum, X25519 and P-256 key exchange.
  The test reports the cipher actually selected by the server.
- TLS 1.2 AES-128/256-GCM works with the requested cipher selection verified.
- Bun downloads the Pi fd/ripgrep archives from GitHub, Hugging Face data and
  the models.dev catalog successfully.
- The offline Pi read/edit/write/bash workload completes without tool errors.
- Memory retry and native fault tests pass on an Apple Silicon Mac.

[Crypto test instructions](../../../tests/arm64/benchmarks/CRYPTO_TESTS.md)
provide repeatable offline checks and a separate public-download test.
Bun does not expose standalone ML-KEM decapsulation in the tested version,
so the offline test checks key derivation rather than decapsulation.

## Device status

The previous iPhone build 821 includes the memory-clear retry fix but lacks
the latest TLS corrections. Version 2.5.0/build823 is intended to include them
with newly generated translations.

Repeated physical-device workloads, memory use and performance still need
checking. Earlier crash reports do not establish the behavior of the new
build. A successful Mac test or app launch is insufficient to confirm that Pi
will remain stable on the iPhone.
